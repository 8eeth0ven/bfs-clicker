# 网站流程与调用图

爬取结束或停止保存后，结果目录会生成 `graph.html`、`graph.json`、`graph.dot`，以及本地查看器 `graph.js` / `graph.css`。结果报告与操作面板均提供“流程与调用图”入口。查看器不加载 CDN，也不访问图中显示的目标地址。

模型可通过 [MCP 服务](mcp.md)启动采集，读取图摘要、分页节点/边、邻域和已知路径。查看器已为大图预建状态/路径索引，按真实关联组织分页；选中节点会保留当前平移、缩放和 SVG，对最近八个视图复用缓存。平行边、自环和返回边使用不同通道，跨页路径仍明确提示省略。

## 使用

```sh
# 面板：开始任务后，从结果区打开“流程与调用图”
npm run view

# 命令行：正常采集会同时生成图
npm run run -- --asset https://console.example.com/ --output output-target
npm run view -- --run output-target --read-only
# 打开本机查看器地址下的 /graph.html

# 已有结果：不启动浏览器、不重新访问目标
npm run graph -- --run output-target
```

离线生成会取得运行目录锁，拒绝与活跃 worker 同时操作；校验配置/断点身份，只读重放 journal，不增加爬取 attempts，不修复或改写源断点。被中断任务的图标为 partial，而不是把旧 `running` 当成完成。生成的图元数据会写回运行结果，方便面板发现入口。

将公开图的五个 `graph.*` 文件保存在一起，可通过本机查看器浏览。直接双击 HTML 时浏览器可能不允许 fetch 本地 JSON，可使用“导入地图”选择同目录 `graph.json`；已验证这个回退。截图是可选的本地 `states/<数字>.png/jpg`。私有目录、登录态和原始流量不属于图查看器文件。

## 能看见什么

| 内容 | 图中表达 |
| --- | --- |
| 页面状态 | 相同 URL 的菜单展开、tab 等不同语义状态分别保留 |
| 操作 | 点击、hover、滚动、选择等；每状态的控件键独立，不会把相同 selector 合并为一个动作 |
| 执行记录 | action_started 的证据 ID 作为执行实例；同动作重放/重试与多次请求分别计数 |
| 页面流程 | 新状态转移、回边、自环、多个控件到同一状态、种子直接入口 |
| HTTP 调用 | 方法、地址、状态、认证轮次、执行上下文和证据；后台请求单独归页面来源 |
| JS 发起线索 | 浏览器 Network initiator 中的函数、脚本位置和调用栈；行列在 UI 中按从 1 开始显示 |
| 静态候选 | 仅在 HTML/JS 中提取、尚未访问的路由/端点，以独立候选边展示 |
| 未完成部分 | 待办、跳过、失败、策略阻断、预算、登录及观察能力缺口 |

HTTP 失败或策略阻断可以证明浏览器尝试过请求，**不能证明服务器收到了请求**。顶部“有响应接口”只统计真实 HTTP 响应，不把 failed/blocked 或静态候选算进去。HTTP 401/403/500 是有响应，但不表示业务成功。

接口边记录“请求发生时的动作上下文”；它与任意异步 JavaScript 的严格因果不同。未精确配对的 JS 发起栈标为上下文线索，不拼成确证流程。没有关联证据时显示后台/页面来源，不根据相邻时间或相同 URL 猜某个按钮触发。

## 如何读图

- **页面流程**：看状态、操作与转移；点击页面可查看入口到这里的已知步骤。
- **接口调用**：看页面/操作到 API，以及浏览器提供的脚本发起位置。
- **全部关系**：联看流程、请求和候选；按需打开“候选线索”“待办 / 跳过 / 失败”。
- 搜索页面标题、操作文字或 URL 后查看相邻节点；“只看周围关系”显示局部关系，避免毛线团。
- 拖动空白处平移，滚轮或按钮缩放。大图每页最多渲染 120 个节点，并说明省略数量；完整数据仍在 JSON/DOT。图中长路径的展示省略有明确标记，不把省略步骤伪装成直接连接。
- 实线代表有确证的观察关系，虚线代表执行上下文或静态线索。JSON、HTML 与 DOT 使用相同的 confidence 口径。

未成功执行的控件可以展示“如何到达该页面”，但不能把待办控件本身的执行说成成功。种子是直接打开地址，不伪装成点击某个不存在的控件。

## 数据与扩展

`graph.json` 为 schemaVersion 1，包含：

```text
run       当前结果状态、资产、时间与停止原因
nodes     state / action / api / route / script
edges     action / transition / request / candidate / initiates / redirect
flows     stateId 对应的已观察发现路径，含是否完整
coverage  范围、预算、待办、缺口、日志读取状态、聚合统计
```

节点与边 ID 是稳定不透明标识。每条边保留 count、最多 12 个证据样本及省略数；状态身份不按 URL 归并。查询参数不同的 API 仍分别保留，未以粗糙模板去重掩盖权限或参数差异。流式扫描每份事件/流量日志，重复终态不会双计；不把接口账本里的历史描述自动升级为响应证据。

Graphviz 用户可读取 `graph.dot`。未来可把同一 JSON 交给 Cytoscape/ELK；本次查看器是自有 SVG 实现，没有引入它们的运行依赖或复制第三方代码。开源依据、许可证和可借鉴模块见 [方案调研](open-source-graph-reference.md)。

`captureInitiators` 默认 true；设 false 会停止新增浏览器发起栈记录，已有普通 HTTP 证据与图仍可生成。脚本栈可用性取决于引擎及请求类型；缺失时不伪造函数。采集时每层最多 12 帧、最多 3 层父栈，图侧使用有界位置样本；它不是完整 JavaScript 函数调用图。现有认证、范围、动作守卫与请求预算继续适用。

## 验证与性能边界

回归覆盖真实点击产生的同 URL 状态、循环/合流、重复 selector、调用上下文、函数发起栈、背景请求、静态未调用端点、策略阻断、重定向、图导出失败与续跑、离线只读恢复、身份不匹配拒绝、CSP、恶意图字符串、目标零外联、移动端和 5000 节点分页。普通报告仍使用 `script-src 'none'`；仅图查看器允许同源本地脚本。

纯日志规模测试固定 3 状态、20 动作、20 API，1k / 10k / 50k 请求输入约 1.81 / 18.18 / 91.21 MB，构图耗时约 35.9 / 320.0 / 1344.3ms。三组均输出 43 节点、42 边，请求计数及证据省略数一致。此为单次本机测量，不包含日志生成、浏览器或 JSON 导出；内部请求/去重索引随日志量增长，不能据此承诺固定内存。

“完整”指本次身份、范围、动作策略、预算与观察窗口内，已经记录的流程可以追溯。队列耗尽不能证明网站所有隐藏业务流程都已穷举；不同输入/角色、closed shadow、canvas、超出采样的 frame、长延迟任务、WS/worker 等可能仍有缺口。浏览器也无法单独还原后端服务→数据库的内部调用；那需要服务端 tracing 数据。图会保留这些边界，不补造关系。

最终本机完整回归：129 PASS / 0 FAIL。默认开启图与发起栈后，同覆盖浏览器对照为分叉树约 1.23 倍、深链约 3.58 倍、120ms 延迟页面约 1.25 倍；详见 [性能结果](performance-implementation.md)。
