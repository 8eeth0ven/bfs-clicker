# iOS Simulator query fixture

A small UIKit app with a query field, a Search button and a result label. It is the installable simulator example; the similarly named `ios_demo` directory contains an unsigned static fixture.

![The sample screen has a query field, search button and result label.](../../../docs/images/readme-light/ios-simulator.svg)

Read the [view implementation](main.m) to see the three controls. For a package you can inspect without launching an app, see the [static fixture](../ios_demo/README.md).
